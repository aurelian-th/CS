# Cryptography and Security (CS) Laboratory Works

**Author:** Tihon Aurelian-Mihai

**Institution:** Technical University of Moldova (UTM), FCIM

This repository contains the laboratory assignments and implementations for the Cryptography and Security course.

## Laboratory modules

- [Lab 1: Caesar Cipher](Lab%201/README.md) — Implementation of single-key Caesar and two-key keyword-permuted Caesar ciphers over the 31-letter Romanian alphabet.
- **Lab 2:** Monoalphabetic cryptanalysis.
- **Lab 3:** Polyalphabetic ciphers.
- **Lab 4:** Block ciphers and the DES algorithm.
- **Lab 5:** Public key cryptography.
- **Lab 6:** Hash functions and digital signatures.
